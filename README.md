## Project description
Chromatic lets university students record each day as a color with an optional title and short note. Saved days appear as colored squares on a monthly calendar. All data stays on the phone.

## Planned features
- **Must:** create, view, edit and delete daily entries; pick a color; monthly calendar and color mosaic; search by title or note; daily reminder notification; data kept offline on the device.
- **Should:** filter by color or date range; basic statistics.
- **Could:** choose the reminder time; label your own colors; extra color palettes.

## Tech stack
Flutter (Dart), SQLite (sqflite), flutter_local_notifications, Android.

## Setup instructions
1. Install Flutter and Android Studio.
2. Clone this repository.
3. Run `flutter pub get`.
4. Run `flutter run` with an Android emulator or phone connected.

The Flutter project will be added in Assignment 2.
